## 🖥️ About The Project

**Arachne-OS** is a fully functional, browser-based desktop environment built from scratch. Just like a spider weaves its web, this project aims to weave together draggable windows, a dynamic taskbar, and interactive apps into a seamless single-page application.

This is my submission for the **Hack Club WebOS 1** mission. The goal is to simulate a complete operating system interface right inside your browser tab—no downloads, no installations, just pure web magic.
